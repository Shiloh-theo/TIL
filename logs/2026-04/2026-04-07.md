## Lesson 10 — React Setup + Fundamentals

### The Core Mental Model
**UI = f(state)** — React's entire philosophy in one line. When data (state) changes, React automatically re-renders the UI to reflect it. You never manually update the DOM.

### Components
JavaScript functions that return UI. The entire app is components nested inside each other:
```jsx
function Button({ label }) {
  return <button>{label}</button>;
}
```

### JSX
Not real HTML — a template syntax that compiles to JavaScript. Curly braces `{}` embed any JS expression:
```jsx
const name = "Shiloh";
return <h1>Hello {name}</h1>; // renders: Hello Shiloh
```

### useState
Stores data that can change. Calling the setter triggers a re-render:
```jsx
const [balance, setBalance] = useState(0);
// Never: balance = 5000 ❌
// Always: setBalance(5000) ✅
```

### useEffect
Runs after the component renders. Empty `[]` = runs once on first load (component mount):
```jsx
useEffect(() => {
  fetchBalance(); // API call on page load
}, []); // [] = run once only
```

### api.js — Single Axios Instance
One base URL, one place to add headers. Change it once, affects every API call:
```javascript
import axios from 'axios';
const api = axios.create({
  baseURL: 'http://localhost:8080/bank'
});
export default api;
```

## Lesson 11 — Auth Pages (Register + Login)

### React Context — Global State Without Prop Drilling
Shares data across the entire component tree. Without it, you'd pass `token` as a prop through every component — tedious and fragile.

```jsx
const AuthContext = createContext();

export function AuthProvider({ children }) {
  const [token, setToken] = useState(null);
  const [user, setUser] = useState(null);

  const login = (userData, jwt) => {
    setUser(userData);
    setToken(jwt);
  };

  const logout = () => {
    setUser(null);
    setToken(null);
  };

  return (
    <AuthContext.Provider value={{ token, user, login, logout }}>
      {children}
    </AuthContext.Provider>
  );
}

export const useAuth = () => useContext(AuthContext);
```

Any component can now call `useAuth()` — no prop drilling needed.

### Why Token Stays in Memory (NOT localStorage)
localStorage is vulnerable to XSS attacks — malicious scripts can read it. Storing JWT in React state means it's gone on page refresh — safer. For this portfolio project this is the correct, secure approach.

### Controlled Inputs — Two Requirements
An input React owns and controls. Two things make it controlled:
1. `value` bound to state
2. `onChange` updating that state on every keystroke

```jsx
<input
  value={formData.email}           // bound to state
  onChange={handleChange}          // updates state on every keystroke
  name="email"
/>
```

### Dynamic Key Pattern — One Handler for All Inputs
```javascript
const handleChange = (e) => {
  setFormData({ ...formData, [e.target.name]: e.target.value });
  // [e.target.name] reads the input's name attribute dynamically
  // One function handles ALL inputs in the form
};
```

### e.preventDefault()
Stops the browser's default form behaviour — a full page reload that wipes all React state:
```javascript
const handleSubmit = async (e) => {
  e.preventDefault(); // without this, page reloads and state is lost
  // ... handle form
};
```

### Axios Interceptors — Attach JWT Automatically
One place to add the Authorization header to every outgoing request:
```javascript
api.interceptors.request.use((config) => {
  const token = /* get from context or state */;
  if (token) config.headers.Authorization = `Bearer ${token}`;
  return config;
});
```

### async/await + Loading State Pattern
```javascript
const handleSubmit = async (e) => {
  e.preventDefault();
  setLoading(true); // show spinner
  try {
    const res = await api.post('/login', formData);
    login(res.data.user, res.data.token);
    navigate('/dashboard');
  } catch (err) {
    setError(err.response?.data || 'Login failed');
  } finally {
    setLoading(false); // always runs — hides spinner
  }
};
```
